How to use this research atlas

Browse conferences at the top and combine tags across eight parallel facets. Robotics, agents, LLMs, VLMs, vector search and recommendation belong to Workload.

  • Workload: Tasks, applications and evaluation workloads. Model families and tasks can overlap, such as LLM + MoE or VLM + Robotics.
  • Technique: Methods including quantization, co-design, compression, caching, scheduling, parallelism, compilation, verification and speculative decoding. Speculative Decoding covers token drafting with verification/sampling, including evidence-backed integrations, kernel support and diagnostic studies; each entry states its scope. Speculation remains the broader parent for speculative execution, prefetching and related techniques.
  • Bottleneck: Performance constraints and metrics, including latency, throughput, memory capacity, memory bandwidth, communication and contention.
  • Deployment: Edge, cloud, cluster or local environments. A cluster does not necessarily imply cloud deployment.
  • Objective: Performance, efficiency, scalability, reliability, correctness, security, energy, cost, quality and usability.
  • Stage: Training, fine-tuning, inference, prefill, decode and data processing. Combine Workload = LLM with Stage = Inference / Serving for LLM inference.
  • Architecture: Computing platforms, near-data computing, memory and interconnect technologies, and system organization. Each entry has separate Architecture evidence and a role: research target, measured testbed, simulated/emulated/synthesized platform, or unresolved. Tags do not imply new hardware. Background and comparator-only mentions are excluded. Heterogeneous means hardware or memory-tier heterogeneity, not different workloads or SLOs. Distributed describes communicating workers/nodes, not on-chip layouts. Runtime / Sandbox is separate from system/device Virtualization. Near-Memory Computing, PIM / CIM and Near-Storage Computing replace the ambiguous Near / In-Memory umbrella. DRAM, SRAM and persistent memory are distinct; software agent memory is not NVM. Overlap with Resource is intentional, but evidence is recorded separately.
  • Resource: Hardware used or discussed, including processors, accelerators, memory, storage and network interfaces.

Evidence and coverage: Classification starts from titles and abstracts, with missing tags supplemented from evaluation sections and experimental setups. Evidence includes PDF page numbers and excerpts. Automated additions have been spot-checked; the collection has not been manually reviewed in full. A mentioned technique or metric may not be the main contribution or demonstrated bottleneck. “Other” covers cases outside the taxonomy or without sufficient evidence, and is excluded from specific-tag coverage.

Collection: 1,133 papers: 1,116 main-conference papers from 2025–2026, 10 ASPLOS 2024 papers, six additional items and the standalone Lachesis paper. Seven complete proceedings are excluded to avoid duplication. Lachesis has no confirmed year. HPDC is a design reference, not a locally indexed venue.

Filtering: Tags within a facet use OR; different facets use AND. Switching facets retains selections. The FACETS overview always shows whole-library coverage; tag counts reflect other active filters.
